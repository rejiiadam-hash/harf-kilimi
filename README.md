# Harf Kilimi

Türkçe kelime bulmaca oyunu. Harfleri parmağınla birleştirip kelime bul, her kelime kilime renkli bir şerit olarak dokunur. 1000 bölüm, gittikçe zorlaşır.

Oyna: https://rejiiadam-hash.github.io/harf-kilimi/

Telefonda ana ekrana ekleyince uygulama gibi tam ekran ve internetsiz çalışır.

- `index.html`, `manifest.webmanifest`, `sw.js`, `icon-*.png`: yayınlanan uygulama
- `src/`: kaynak (`src.html`), kelime listesi (`words.json`) ve derleme betiği (`build.py`)
